# DotOffice

Pure managed .NET library for converting office documents — no LibreOffice, no native binaries, MIT licensed.

> **Status:** early development. Not usable yet.

```csharp
await DocumentConverter.ConvertAsync("invoice.docx", "invoice.pdf");
```

## Goals

- DOCX/XLSX/PPTX → PDF with high fidelity
- 100% managed code: runs anywhere .NET runs (containers, Linux, AOT)
- No GPL/AGPL or restrictive-license dependencies

## Packages

| Package | Purpose |
|---|---|
| `DotOffice.Core` | Format-neutral document model |
| `DotOffice.Fonts` | OpenType parsing, subsetting, font resolution |
| `DotOffice.Pdf` | Low-level PDF writer |
| `DotOffice.Layout` | Line breaking, pagination, tables |
| `DotOffice.Docx` / `Xlsx` / `Pptx` | OOXML readers |
| `DotOffice.Converter` | Public facade |

## Roadmap

1. PDF writer + font embedding/subsetting ✓
2. DOCX → PDF: paragraphs, styles, lists, tables, headers/footers, images ✓
3. DOCX polish: fields, floats, columns, footnotes, complex scripts including Indic ✓ (Sinhala, Tibetan, Myanmar and Khmer shaping not yet supported)
4. XLSX → PDF: milestone 1 ✓ (cells, styles, number formats, merges, page setup, print areas/titles, breaks, headers/footers); milestone 2 ✓ (rich-text runs, rotated and stacked text, gradient fills, pictures from drawings with anchors/crop/rotation, conditional formatting, fraction formats)
   - Milestone 3 ✓ (flipped pictures, multiple print areas, standard paper sizes, the workbook's `[ColorN]` palette, comments as an end-of-sheet list, shapes and charts, and the conditional-formatting leftovers below)
   - Milestone 4 ✓ (chart types and options, shape fills, arrowheads and paths, conditional formatting across sheets, custom icons and data-bar axes, pivot tables without a blanket warning, all paper sizes, first page numbers, fill alignment)
   - Milestone 5 ✓ (BMP, GIF and TIFF pictures; print titles outside the print range and headers/footers that scale with the sheet; chart transparency, trendlines, error bars, manual layouts and a category axis that follows a reversed value axis; pattern fills, theme gradient styles, shadows and custom geometry with guide formulas; lookup and reference functions, whole-column references and x14-only data bars in conditional formatting; pivot styles of the common Light and Medium families and pivot-area formats)
   - Conditional formatting: cellIs, expression (references on this or another sheet including quoted sheet names, defined names that stand for a reference, a range or a constant, whole-column and whole-row references such as `$A:$A` and `1:1`, arithmetic/comparison/`&`, and AND/OR/NOT/IF/MOD/ROW/COLUMN/ISBLANK/COUNTIF/SUM/… plus SUMPRODUCT (with array arithmetic over ranges), VLOOKUP/HLOOKUP, INDEX/MATCH, and OFFSET and INDIRECT (from any numbers or text the formula computes, A1 style) — a fixed function list; all rules are applied once every sheet has been read), top10, aboveAverage (with standard deviations), duplicate/unique values, text/blank/error rules, `timePeriod` rules (relative to `XlsxReaderOptions.Today` or the current date), 2- and 3-color scales, data bars (solid or gradient, borders, negative values, axis position automatic/middle/none, axis color and right-to-left direction from the x14 extension), every standard 3-, 4- and 5-icon set including custom icons (`x14:cfIcon`, also "no icon"), and rules that exist only in the x14 extension (data bars, 3Stars, 3Triangles, 5Boxes, `xm:f` formulas with an inline `x14:dxf`); priority, stopIfTrue and dxf font/fill/border/number-format overrides
   - Shapes and text boxes: preset geometry (rectangle, rounded rectangle, ellipse, triangle, right triangle, diamond, parallelogram, trapezoid, hexagon, the four block arrows, lines and connectors), custom geometry (paths of lines, curves and arcs, with coordinates that are numbers or guides — adjust values and `gdLst` formulas such as `*/`, `+-`, `sin`, `at2`, `pin`), bent connectors 2–5 and curved connectors 2–3 with their adjustments, solid fills and real gradient fills (linear; path gradients are circular or, for `path="rect"`, concentric rectangles, clipped to the outline), picture fills (`blipFill`, stretched over the frame and cut at the outline), pattern fills drawn as real hatches (horizontal, vertical, diagonal and cross families; dot, check and weave patterns as a tint of the two colors), fills from the theme's style references (gradients for `fillRef` 2–3), outer shadows (an offset translucent copy; with a blur radius a 3 × 3 grid of faint copies spread over the radius that add up to the shadow's opacity), outline with width and dash, arrowheads (triangle, stealth, arrow, oval, diamond; the line stops at the base of a filled head), theme style references, text with alignment/anchor/insets, rotation, flips and groups. Gaps: custom geometry whose guide formulas use something else than the standard operators is skipped (`xlsx.drawing`); other preset geometries are drawn as rectangles, curved connectors 4–5 are rounded bent routes, tiled picture fills are stretched (`xlsx.drawing-approximated`); custom-geometry paths with holes are filled without them; glows, soft edges, blurs and rotated groups are ignored
   - Charts: column and bar charts (clustered, stacked, 100 % stacked), line charts (markers, smoothed lines), area, pie, doughnut (rings per series, hole size, first-slice angle), scatter (marker-only or joined, own horizontal scale), bubble (area follows the size) and radar charts (open or filled), and combination charts of bar, line and area groups with a secondary value axis (own scale, labels, title, number format); title, legend, axis titles, gridlines, an Excel-like automatic scale, fixed min/max/major unit, number formats, reversed and logarithmic axes, per-series and per-point colors, value/percent data labels, translucent fills (`alpha`) on bars, areas (also on the secondary axis) and bubbles, trendlines (linear, exponential, logarithmic, power, polynomial, moving average, with forward/backward periods; on column, bar, line, area and scatter series, on stacked groups following the stacked totals; with their equation and R² when asked), text formatting of the title, axis labels, axis titles, legend, data labels and trendline labels (size, color, bold, italic, font; the chart's base style colors every part), a manually placed legend, error bars (fixed, percentage, standard deviation, standard error, custom; either direction on scatter charts; they extend the automatic scale) and manual plot-area and title layouts. Data comes from the chart's cache, else from the cells. **Not drawn** (reported by name in `xlsx.drawing`): stock, surface, pie-of-pie/bar-of-pie, all 3-D charts and the newer chart types (waterfall, funnel, …); a combination with a group of another kind (say scatter) draws only the category-axis groups (`xlsx.drawing-approximated`). With a reversed value axis the category axis and its labels move to the top (to the right for bars). Approximations: smoothing is a Catmull-Rom spline, log axes are not combined with stacking, manual layouts that are not measured from the chart's edge are ignored, a manual legend keeps its position but not its size and does not shrink the plot, trendline labels sit above the line's far end (their manual layout and number format are ignored, equations show five significant digits), text rotation and per-point label formatting are ignored; bubble 3-D, secondary axes of horizontal bars and of scatter/bubble charts are ignored
   - Comments: listed after the sheet (cell, author, text) when the page setup prints them (`atEnd`; `asDisplayed` falls back to the list with a warning). Threaded comments show their legacy fallback text, and floating notes are not drawn
   - Not yet supported (each emits a warning): conditional-formatting rules using unlisted functions or names that are not plain references (those rules are ignored) and rules reading a sheet that does not exist; pivot tables print their cached cells without a warning; a table with a style warns that it is drawn approximately (the Light 1–7 and 15–21 and Medium 1–7 and 8–14 families: what they highlight — header, totals, bands, tint — not Excel's exact shades) or that the style is not applied (the other styles, custom table styles), and warns when a pivot-area format picks particular items (formats on the whole table, the corner, the column headings, the data, the labels, the grand totals and the field buttons are applied) or the cache refreshes on load; paper size ids outside the standard list use Letter
   - Paper sizes: every SpreadsheetML `paperSize` id with a fixed size (1–47, 50–118); the "rotated" ids take their upright twin's size and the page's own orientation decides
   - Conditional formatting gaps: only cells in the used range or print areas are formatted — like Excel and LibreOffice, which print only the used range, so a fill on empty cells beyond the data is not drawn unless a print area includes them; INDIRECT reads A1-style text only; a text cell holding `""` counts as blank; ties and rounding follow Excel only approximately
   - Number formats: locale-specific built-in ids 27–36/50–58 (General), `*` fill ignored, fractions ignore thousands separators
   - Pictures: PNG, JPEG, BMP (1–32 bits, uncompressed, bitfields or RLE4/RLE8), GIF (first frame, transparency, interlacing) and TIFF (baseline: 1–8-bit gray or palette, 8-bit RGB/RGBA, uncompressed, PackBits or LZW, with the horizontal predictor); JPEG/CCITT TIFF, EMF and WMF draw a placeholder with a warning (`pdf.image-format`; EMF/WMF need a vector interpreter, which was judged out of proportion)
   - Layout: text trimmed per character at cell edges, print titles before the print range are repeated on every page (those after it are not), headers and footers scale with the sheet unless `scaleWithDoc` is off, text that spills past the used range extends it (but is cut at an explicit print area, like Excel), header/footer pictures (`&G`, from the legacy VML drawing; a picture sits above its section's text, one picture per section, shown on whichever header variant has `&G`) are drawn at the VML shape's size, `&D`/`&T` use the current date/time, row autofit is approximate (rotated and rich text included), text with fill alignment repeats only without rich-text runs, fit-to-page never enlarges and ignores manual breaks (like Excel)
5. PPTX → PDF / PNG
6. ODF readers, legacy DOC/XLS
